## 我叫FSVC

基于 Three.js 构建的交互式三维校园模型，以完全建成后的校园为展示状态。项目包含教学主楼、图书馆、宿舍区、食堂、风雨长廊、体育场馆、操场、护城河及校园绿化，可通过鼠标和键盘自由参观。

#### 和这个地球一样牛逼

- **完整校园场景**：建筑、道路、水系、运动场地和绿化统一呈现。
- **建筑细节建模**：包含城堡式教学楼、统一风格宿舍楼、食堂入口及带连续拱洞的风雨长廊。
- **自由相机漫游**：支持旋转、平移、缩放、俯视切换和机位复位。
- **流畅交互体验**：采用 `deltaTime` 帧时间差、自适应平移速度、静态阴影和异步着色器预热。
- **程序化材质**：立面、屋顶、地面及环境纹理由 Canvas 动态生成。
- **一键启动**：Windows 下可通过 BAT 启动器自动安装依赖、启动服务并打开浏览器。

## 快速启动

### Windows 一键启动

双击项目根目录中的 **`启动校园模型.bat`**。

启动器会自动检查 Python、首次安装 npm 依赖、启动本地服务，并打开：

```text
http://127.0.0.1:8000/
```

关闭 `Campus Model Server` 窗口即可停止服务。

### 手动启动

环境要求：Node.js、npm、Python 3。

```bash
npm install
python -m http.server 8000
```

然后访问 `http://127.0.0.1:8000/`。

> 请通过本地 HTTP 服务访问，不要直接双击 `index.html`，否则 ES Module 和资源加载可能受到浏览器限制。

## 操作方式

| 操作 | 功能 |
| --- | --- |
| 鼠标左键拖动 | 环绕旋转视角 |
| 鼠标右键拖动 | 平移观察目标 |
| 鼠标滚轮 | 拉近或拉远视角 |
| 方向键 | 沿当前视角水平移动整个摄像机 |
| `T` | 切换校园俯视 / 初始机位 |
| `R` | 恢复初始机位 |

方向键移动速度会随观察距离自动调整，便于校园整体浏览和建筑近景查看。

## 技术栈

- Three.js `0.170.0`
- JavaScript ES Modules
- Canvas 2D 程序化纹理
- Python HTTP Server
- Playwright Core（浏览器验证）
